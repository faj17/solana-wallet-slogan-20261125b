One line, a slogan for a Solana wallet agent (100 characters, 17 words):

> While you sleep, your Solana wallet stays awake — signing, swapping, watching, so you don't have to.

The image is a night shift: you sleep, the wallet stays awake. The work is named plainly — signing, swapping, watching — so a newcomer reads the promise in one breath, and the contrast (sleep / awake, you / it) makes the line easy to repeat. Nothing is promised the wallet cannot do: it works while you rest, it does not make you rich.

## Run it

```sh
python3 main.py
```

Writes the slogan to `/output/entry.txt`.
